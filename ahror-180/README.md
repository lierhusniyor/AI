# Ахрор: 180 дней 🔥

Ежедневное приложение «С кухни в IT»: урок дня по плану на 180 дней (Python → Git → Claude → сети и Linux → кибербез → портфолио), счётчик дней, серия, чек-лист, таймер и готовые промпты для Claude.

## Как поставить на телефон (Samsung / Android)
1. Открой ссылку на приложение в Chrome.
2. ⋮ → «Добавить на главный экран» / «Установить приложение».
3. Открывай каждый вечер после смены.

Прогресс хранится в браузере телефона. Раз в неделю: вкладка «Правила» → «Скопировать прогресс» и сохрани код в заметках.
